# 🤠 Traveling‑Cowboy 旅行牛仔

> 基于 HTML5 + JavaScript 的网页小游戏Demo，浏览器直接运行。

🔗 **在线体验(GitHub Pages)：** https://kbrown102.github.io/Traveling-Cowboy/

## 📖 项目介绍
旅行牛仔，一个网页端休闲小游戏原型。
纯前端实现，无需下载客户端，打开浏览器即可游玩。

## ✨ 功能特性
- 🌐 浏览器直接运行，支持 GitHub Pages 在线部署
- 🎮 基础游戏交互逻辑
- 📂 无第三方框架依赖，原生JS实现，便于二次修改学习

## 🚀 本地运行方式

### 方式1：直接本地打开
1. Clone 项目到本地
```bash
git clone https://github.com/KBrown102/Traveling-Cowboy.git
```

2. 项目根目录打开 `index.html` 即可开始游戏。

> 
> ⚠️部分浏览器本地直接打开 html 会有跨域静态资源报错，推荐使用本地静态服务。

### 方式 2：本地简易服务（推荐）

如果本地直接打开资源加载异常，可以启动简易 http 服务：

```
# python3
python -m http.server 8000
```

浏览器访问 `http://127.0.0.1:8000`
