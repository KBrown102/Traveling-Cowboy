# 🤠 Traveling‑Cowboy 旅行牛仔

> 基于 HTML5 + Canvas 2D 的**治愈系漫游场景**（动态壁纸风格），浏览器直接运行。

🔗 **在线体验(GitHub Pages)：** https://kbrown102.github.io/Traveling-Cowboy/

## 📖 项目介绍
旅行牛仔，一个零依赖的 Canvas 2D 治愈系漫游场景：牛仔骑马剪影穿过 13 个循环场景，五分钟一昼夜，配动态天气、飞鸟与鼠标光影，打开浏览器即可漫游。
纯前端实现，无需下载客户端。

## ✨ 功能特性
- 🌐 浏览器直接运行，支持 GitHub Pages 在线部署
- 🌅 **13 个循环场景**（草原 / 沙漠 / 雪原 / 海边等）无缝衔接
- 🕐 **五分钟一昼夜**：日出 → 正午 → 日落 → 星空，配色随太阳角变化
- 🌦️ **动态天气系统**：云 / 雨 / 雪 / 沙尘暴 / 雾，牛仔姿态随天气变化
- 🐦 **飞鸟点缀**：海鸥式剪影双翼扇动，恶劣天气与深夜隐藏
- 🖱 **鼠标光影**：光线随鼠标互动，氛围可玩
- 📂 无第三方框架依赖，原生JS实现，便于二次修改学习

## 🚀 本地运行方式

### 方式1：直接本地打开
1. Clone 项目到本地
```bash
git clone https://github.com/KBrown102/Traveling-Cowboy.git
```

2. 项目根目录打开 `index.html` 即可开始游戏。

> 
> ⚠️部分浏览器本地直接打开 html 会有跨域静态资源报错，推荐使用本地静态服务。

### 方式 2：本地简易服务（推荐）

如果本地直接打开资源加载异常，可以启动简易 http 服务：

```
# python3
python -m http.server 8000
```

浏览器访问 `http://127.0.0.1:8000`
